# Security Audit — SIP-01/Dsearch — 2026-10-20

## Summary
Search engine + dashboard: React/Vite frontend, Cloudflare Worker API proxy (`worker.ts`), and a multi-service backend (Meilisearch crawlers, NIP-50 relay, abuse-api). The Cloudflare Worker proxy is exemplary: strict CORS allowlist (never `*`), per-IP rate limiting, NIP-98-signed admin writes, server-side key injection, sanitized upstream errors. The Node `backend/abuse-api` is weaker: CORS `*` on admin endpoints, injectable Meilisearch filter strings, and no rate limit on report submission. No committed secrets. Findings: 0 CRITICAL / 1 HIGH / 2 MEDIUM / 2 LOW.

## Findings
| ID | Severity | File/Area | Issue | Recommended fix |
|----|----------|-----------|-------|-----------------|
| DS-H1 | HIGH | backend/abuse-api/src/index.ts (`sendJson`) | `Access-Control-Allow-Origin: *` with `Access-Control-Allow-Headers: Authorization` on every response, including the Bearer-token-admin endpoints (`GET /api/reports`, `PATCH /api/reports/:id`). Any origin's JS can drive the admin API with a token; combined with no Origin checks this widens token-theft/XSS blast radius. | Allowlist dashboard origins like `worker.ts` does; never reflect `*` on Authorization-accepting routes. |
| DS-M1 | MEDIUM | backend/abuse-api/src/index.ts (`handleSearch`) | Meilisearch filter built by string interpolation of unvalidated query params: `` `source = "${source}"` `` and `` `kind = ${kind}` ``. A crafted `source` value breaks out of the string literal and injects arbitrary Meilisearch filter expressions (index data exfiltration/enumeration). | Validate `source` against `^[a-z0-9_-]+$`, coerce `kind` with `parseInt`+isFinite, or use Meilisearch's parameterized filter bindings. |
| DS-M2 | MEDIUM | backend/abuse-api/src/index.ts (`handleSubmitReport`) | `POST /api/report` is unauthenticated with no rate limit; each report writes a JSON file to disk (REPORTS_DIR). Trivial disk-fill / report-spam DoS. | Add per-IP rate limiting and a max report count/size cap. |
| DS-L1 | LOW | backend/abuse-api/src/index.ts (`isAdmin`) | Admin token compared with `===` (not constant-time). Fail-closed default (empty token disables admin) is good. | Use `crypto.timingSafeEqual`. |
| DS-L2 | LOW | repo root | `.gitlab-ci.yml` committed in a GitHub-hosted repo (dead CI config); `.env.example` ships placeholder tokens only (fine). | Remove stale CI file. |
