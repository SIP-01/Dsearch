# Security Audit — Dsearch — 2026-10-20 (re-run 2026-10-21)

## Summary
Search engine + dashboard: React/Vite frontend, Cloudflare Worker API proxy (`worker.ts`), and a multi-service Node backend (Meilisearch crawlers, NIP-50 relay, abuse-api). **Delta vs `audit/2026-10`: yesterday's HIGH is NOT fixed — `backend/abuse-api/src/index.ts` is unchanged: CORS `*` on every response including admin routes, an injectable Meilisearch filter string, and unthrottled report writes.** The Cloudflare Worker proxy remains exemplary (strict origin allowlist, per-IP rate limit, NIP-98-signed admin writes, server-side key injection, sanitized upstream errors). New this run: a committed live AI-provider key in the frontend (documented public-by-design) and insecure docker-compose default credentials. Findings: 0 CRITICAL / 1 HIGH / 4 MEDIUM / 1 LOW.

## Findings
| ID | Severity | File/Area | Issue | Recommended fix |
|----|----------|-----------|-------|-----------------|
| DS-H1 | HIGH | backend/abuse-api/src/index.ts (sendJson + OPTIONS handler) | `Access-Control-Allow-Origin: *` on ALL responses including admin endpoints (`GET /api/reports`, `PATCH /api/reports/:id`). Bearer-token auth blunts browser CSRF, but any origin can call/read the API — combined with the weak default admin token (DS-M3) this is remotely exploitable on default deploys. **Still present since 2026-10-20 audit.** | Reflect an allowlisted origin list like worker.ts does; never `*` on authenticated routes |
| DS-M1 | MEDIUM | backend/abuse-api/src/index.ts (handleSearch) | Meilisearch filter injection: user-controlled `source`/`kind` query params are string-interpolated into `filter` (`` `source = "${source}"` ``) without escaping — a `"` in `source` breaks out into arbitrary filter expressions | Build filters via SDK parameterization or strict allowlist/escape of values |
| DS-M2 | MEDIUM | backend/abuse-api/src/index.ts (handleSubmitReport) | POST /api/report has no rate limit and writes one JSON file per request to a volume — disk-fill / inode-exhaustion DoS, and `listReports` re-reads the whole directory per admin call | Add per-IP rate limiting + body/cap quotas; move to SQLite |
| DS-M3 | MEDIUM | docker-compose.yml | Insecure defaults: `ABUSE_ADMIN_TOKEN:-change-me` and `MEILI_MASTER_KEY:-change-me` — a copy-paste deploy enables admin endpoints and the Meilisearch master API with publicly-known credentials | Fail closed: no default; refuse to start when unset (code already disables admin on empty token — compose defeats that) |
| DS-M4 | MEDIUM | src/lib/aiConfig.ts:64 | **Committed live API key**: `COMMUNITY_AI_KEY = 'sk-VPVV…'` (ppq.ai), ships in the public frontend bundle. Documented "public by design, shared + rate-limited" — still a live credential in git history; abuse is bounded only by the provider's own limits | Confirm provider-side rate/cost caps are enforced on this key; add monitoring + rotation plan; consider removing now that the engine-proxy tier exists |
| DS-L1 | LOW | repo | GHAS/secret scanning not enabled; no Dependabot config observed | Enable secret scanning + push protection |
